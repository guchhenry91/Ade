# Autonomous Intelligence Engine

## Purpose
Enable proactive opportunity detection and auto-reporting under Commander supervision.

## Agent monitoring scopes
- Sports Prediction Agent: NBA, NFL, EPL/UCL/La Liga, injuries, line movement, sharp indicators
- Betting Intelligence Agent: odds movement, line shifts, inefficiencies, sharp activity
- TikTok Content Agent: trend signals, viral audio velocity, hashtag growth, format shifts
- Job Research Agent: LinkedIn, career pages, job boards; Helpdesk/IT Support/Technical Support/Broadcast Ops; salary £35k–£45k

## Commander filter
Only publish alerts when:
- confidence >= 60%
- clear opportunity detected
- trend velocity above baseline

## Alert format
Each topic alert includes:
- opportunity description
- confidence score
- supporting data
- recommended action

## Topic destinations
- sports-analytics
- betting-insights
- job-opportunities
- tiktok-production
